## Overview

Adribot is a lightweight chatbot project delivered through the web. The interface is built with HTML and can be accessed from a hosted page or run locally using a web server.

Because it works in the browser rather than requiring a native desktop installation, Adribot is useful for demonstrations, experimentation, and trying out a straightforward bot interface in a web environment.

## Getting Started

Download the repository by cloning it:

```bash
git clone https://github.com/brooksnathanjjsv1228/adribot-web-chatbot.git
cd REPO
```

You may open the primary HTML file directly for a basic local preview. Serving the files over HTTP generally provides more dependable browser behavior:

```bash
python -m http.server 8000
```

Once the server is running, open:

```text
http://localhost:8000
```
